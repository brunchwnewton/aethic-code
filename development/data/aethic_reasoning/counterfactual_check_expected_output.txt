1. The four-attribute witness (Theorem: Cautious Monotony fails)
==============================================================================
A states s; closure: [('s', True), ('y', True)]
y's minimal supports: [[('s', True)]]
  reopen for x    : intermediates [[('s', True), ('y', True)]]
  pockets of pi_x    : ['(x, s, y, z)']
  reopen for x & y: intermediates [[]]
  pockets of pi_x & y: ['(x, ~s, y, ~z)', '(x, ~s, y, z)', '(x, s, y, z)']
  x |~ y : True | x |~ z : True | x&y |~ z : False | x |~ ~y : False
  => Cautious Monotony fails at (x, y, z); Rational Monotony fails on the same instance.

2. Retention: the streetlight-type example  (r = red, t = stopped; law r -> t; A = {~r, ~t})
==============================================================================
  declared supports of ~r: [[('r', False)]] (a stated entry; ~t is not among its grounds)
  with retention   : intermediates [] -> INFEASIBLE
  without retention: intermediates [[]] -> pockets ['(r, t)']
  => the retention clause is what makes the evidential-minimal streetlight infeasible.

2b. Cut without nesting (Proposition): priorities keep the generalization p over the particular r
==============================================================================
  reopening x, tie-keeping maxima: [[('p', True), ('y', True)], [('r', True), ('y', True)]]
  priority selects: [[('p', True), ('y', True)]] -> pockets under x: ['(p, ~r, x, y)']
  reopening x & y: [[('r', True)]] -> pockets: ['(~p, r, x, y)']
  x |~ y: True | x&y |~ r: True | x |~ r: False (x |~ ~r: True)
  => Cut fails where the priorities select among inclusion-incomparable maximal restrictions.

3. Minimality: a three-attribute Cautious Monotony counterexample (law z -> y; A states z)
==============================================================================
  pockets of pi_x  : ['(x, y, z)']
  pockets of pi_x&y: ['(x, y, ~z)', '(x, y, z)']
  x |~ y, x |~ z, x&y |/~ z : True
  => three attributes suffice; the four-attribute witness is not the smallest instance.

4. Left Logical Equivalence: x versus x & (y or ~y) on the witness
==============================================================================
  NORMALIZE=False: targets of x&(y|~y) = ['x', 'y'];  x&(y|~y) |~ z : False  (x |~ z : True)
  NORMALIZE=True : targets of x&(y|~y) = ['x'];  x&(y|~y) |~ z : True  (x |~ z : True)
  => un-normalized, the unrestricted conjunct reopens y and LLE fails; normalized, it contributes no target and LLE holds.

5. Comparators on the witness
==============================================================================
  premise-MAX (maximal consistent stated facts): x []-> y True, x []-> z True, x&y []-> z True
  basis-retraction (Veltman-type): x []-> y False, x []-> z False, x&y []-> z False
     worlds reached under x: ['(x, ~s, ~y, ~z)', '(x, ~s, y, ~z)', '(x, s, y, z)']
  => the maximal-consistent-facts comparator keeps s and validates the instance; the basis-retraction
     clause affirms neither x []-> y nor x []-> z, so the Cautious Monotony instance does not arise for it.

7. Antecedent strengthening, contraposition and transitivity
==============================================================================
  strengthening on the witness: x |~ z True | x&y |~ z False
  contraposition on the witness: x |~ y True | ~y |~ ~x False | pockets under ~y: ['(~x, ~s, ~y, ~z)', '(~x, ~s, ~y, z)', '(x, ~s, ~y, ~z)', '(x, ~s, ~y, z)']
  transitivity (law c -> d; state {c, e}): d |~ e True | e |~ c True | d |~ c False | pockets under d: ['(~c, d, e)', '(c, d, e)']
  => all three patterns fail, each by a witness: reopening d clears its ground c, so d |~ e and e |~ c do not chain.
