It lists every file in this folder and can zip them all in the browser. HOW IT FINDS THE FILES 1. Jekyll writes the folder's file list into this page at build time (the "paper-data" block below), so anything you drop into this folder, including subfolders, is picked up automatically on the next build. Nothing to maintain. 2. If the page is ever served without Jekyll, it falls back to a manifest.json in this folder: a JSON array of relative paths, e.g. ["paper1.pdf", "drafts/paper2.pdf"]. Generate one from inside this folder with: python3 -c "import os,json;print(json.dumps(sorted(os.path.relpath(os.path.join(r,f)).replace(os.sep,'/') for r,_,fs in os.walk('.') for f in fs if f not in ('manifest.json','index.html')),indent=1))" > manifest.json LOCAL TESTING: run `bundle exec jekyll serve` (or `jekyll serve`) from the site root and open http://localhost:4000/development/papers/ (adjust the path if the site lives in a subfolder). Opening the file directly from disk won't work, because browsers block file:// pages from fetching files. {% endcomment %}
